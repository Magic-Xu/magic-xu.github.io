# 小麦在野：设计与交互规范

这份规范供后续维护网站的人和开发代理使用。新增功能应融入既有网站：真实山野带来空间感，纸色页面承载阅读，森林绿连接导航和操作，宋体标题形成个人气质，微动画解释状态变化。

先找到相似页面或组件，沿用其结构与变量，再处理新功能特有的状态。本文的**持续约定**用于保持体验；表格中的尺寸、时长和性能参数是**当前实现基准**，可以根据内容与验证结果调整。用户明确要求的新方向优先，并同步维护规范。

页面视觉基准更新为 2026-10-04 验收的五项导航与随笔、足迹空页版本；电台参考图展示六频道共用底部曲库的布局。截图反映布局与层级，动态山谷的每一帧不必相同；下文行为与参数随实现维护。

2026-10-05 补充随笔、地点目录和「相机里的回忆」相册布局，正式构建展示已确认的内容。未公开的内容仍通过本地草稿预览审阅，访客页面不显示内部状态说明。

## 设计方向

| 需要持续保持 | 新功能如何接续 |
| --- | --- |
| 真实自然的山野与可信纵深 | 首页保持航拍般的空间、光影和缓慢穿行；选择有主体的景观，不要求同时出现山、河、湖、海等所有元素。 |
| 首页有视觉记忆，内页适合阅读 | 主要视觉表现集中在山野首屏；文章、作品和说明页通过文字、留白、图片与细线组织信息。 |
| 纸色、低饱和森林绿和宋体标题 | 沿用全站色彩变量与字体角色；功能状态需要额外颜色时，限定用途与作用范围。 |
| 大小有别的内容层级 | 一个明确的主标题或重点项目，其他内容降低权重；长列表沿用行式排布。 |
| 动作连续，控制权明确 | 展开收起有中间过程，快速反向操作可以接续；只在明确的输入下改变用户正在控制的内容。 |
| 音乐作为陪伴 | 入口小而安静，播放由访客主动发起；翻阅网站时保持连续。 |

新功能的独特性优先来自内容和交互含义。整页更换主题色、把普通内容都包成带阴影的圆角卡片、给每段内容增加入场表演，都会改变目前的视觉重心。确有新的产品需要时，作为整体设计变化讨论与验证。

## 色彩与材质

基础变量定义在 [`global.css`](../src/styles/global.css) 的 `:root`。新增通用样式使用变量，避免重复写一套相近色值。

| 变量 | 当前值 | 用途 |
| --- | --- | --- |
| `--color-paper` | `#eeece3` | 页面纸色、电台底色、深绿按钮上的浅色文字 |
| `--color-text` | `#28352f` | 主标题与主要正文 |
| `--color-muted` | `#606c5d` | 日期、状态、次级说明 |

| `--color-surface-raised` | `#e5e6db` | 基础变量中预留的浅层表面色 |

`--color-coral` 当前与 `--color-accent` 同值，是现有命名；新增样式使用语义明确的 `--color-accent`。

局部色彩承担具体角色：首页主标题为 `#f2f1db`，导航为 `#e9ebd9`；深绿半透明遮罩保障山景上的可读性。电台选中项使用 `#e0e4d5`，播放失败提示使用 `#944128`；阅读进度条为 `#6b8154`。这些值属于相应组件，不自动扩展为另一套全站配色。

页面以轻量细线分区。内容行保持开放，圆角和柔和阴影主要用于浮动电台；圆形用于唱片、播放等控制。电台外壳当前收起圆角 `34px`、展开 `22px`，封面圆角 `8px`。订阅页等文字工具沿用简洁的直边输入框与按钮。品牌 Logo、作品图和音乐封面保留素材自身的色彩。

## 字体、层级与留白

- `--font-serif`：本地 Noto Serif SC，回退 Songti SC / STSong。用于标题、导航和部分介绍性文字。
- `--font-sans`：系统无衬线字体。用于正文、元信息、播放器操作和小字号状态。

| 布局角色 | 当前基准 |

## 微动画与操作反馈

### 节奏基准

CSS 常用缓动为 `--ease-out: cubic-bezier(.2,.75,.25,1)`；面板尺寸变化使用 GSAP `power3.inOut`，内容进入常用 `power2.out` / `power3.out`。用缓入缓出和小幅位移保持平稳。

| 交互 | 当前实现 | 需要保持的感觉 |
| --- | --- | --- |
| 链接、按钮、导航 | 颜色约 `250ms`，导航下划线 `400ms`；箭头 `350ms`，一般位移约 `4px` | 轻微回应，文字位置稳定；返回/向下箭头保持各自方向。 |
| 电台展开/收起 | 外壳 `620ms / 500ms`，`power3.inOut`；内部淡入淡出约 `180–380ms` | 唱片入口连续变成面板，收起回到原处；无突然跳尺寸。 |
| 曲库展开/收起 | 内容和电台外壳同步 `480ms`，`power3.inOut` | 面板随内容生长，关闭后不残留空白。 |
| 歌单/频道切换 | 同一内容区内淡出 `200ms`，错开 `80ms` 后淡入 `320ms`，水平位移 `12px`，`power2.out` | 上方封面、进度与播放按钮保持稳定；频道两列排列，选完返回对应歌单和切换入口焦点。 |
| 电台首次出现 | `900ms`，`power2.out`，向上 `12px` 并淡入 | 轻量进入；点击可立即完成入场并操作，站内切页不重复。 |
| 切歌 | 封面 `400ms` 从 `.94` 缩放到 `1`；标题 `350ms`、位移 `5px` | 辨认出内容已更换，操作仍可连续进行。 |
| 音乐播放状态 | 唱片 `16s` 匀速一圈，信号条约 `.9s` 交替起伏 | 只在播放时运动，暂停时安静。 |
| 作品/足迹详情 | 高度 `520ms`，内容淡入/位移 `300ms`，箭头 `500ms` | 详情在原位置打开，关闭结束后恢复原生折叠状态。 |
| 首页文案进入 | CSS 首次绘制开始，`1150ms`，子项错开 `120ms`，位移 `28px` | 每次进入页面播放一次；脚本到达、资源就绪和偏好切换不重播。 |
| 首页底部入口 | 来源与探索 `900ms`，错开 `100ms`，位移 `10px`；漫游控制就绪后 `850ms`、错开 `80ms` | 底栏预留稳定高度，控件加入不顶动标题或探索入口；探索不等待三维场景。 |
| 内页标题组进入 | `720ms`，错开 `70ms`，位移 `14px` | 仅已标记的标题组轻量进入。 |
| 山景就绪与进入漫游 | 静止场景淡入 `1.8s`，交接后约 `1.2s` 启动前进；高清细节混入约 `1.4s`；文案透明度 `1s`、位移 `1.4s` | 静态首帧与三维构图对齐，交接时不提前移动；进入漫游时文字自然退场。 |

### 持续约定

1. **动画可中断、可反向。** 连续点击、动画中途关闭或切换歌单，以当前可见状态接续；清理旧动画，最终尺寸、透明度与展开状态一致。
2. **可见状态与可操作状态一致。** 收起内容不可被键盘误聚焦；同步 `hidden`、`inert`、`aria-expanded` 或 `aria-pressed`。关闭浮层后恢复合理焦点，外部点击不抢走用户的新焦点。
3. **按变化选择动画属性。** 普通反馈优先 `transform` 和 `opacity`；电台外壳、歌单与作品详情确实需要高度变化，测量实际内容并在结束后恢复自然布局。电台尺寸动画限制在固定浮层内。
4. **尊重减少动态效果。** `prefers-reduced-motion` 下直接到最终状态，关闭装饰运动；偏好在页面打开后发生变化也要正确收敛。不能让内容依赖动画完成才可访问。
5. **动作有含义。** Hover 提示可操作性；展开说明层级；播放动效表达状态。新增内容不默认附带循环漂浮、长距离位移或滚动劫持。

## 山野与电台的交互约定

### 山野首页

当前场景通过真实高程与航拍影像构建约 `40 × 40km` 的三维地形，沿约 `23km` 闭合路线飞行。视点应具有真实空间中的前进与遮挡关系；新增景观保持自然比例、清晰远近层次和连续路线。保持对主要文案的可读遮罩。关于资源维护与来源，见 [README](../README.md#视觉资源) 和 [SOURCES.md](../public/landscape/SOURCES.md)。

- 普通鼠标移动、移出再移入、未产生拖动的单击不改变方向。桌面按住主鼠标左键拖动才介入观察；当前启动阈值为 `5px`。链接、按钮和表单的操作不启动场景拖拽。
- 拖动从当前角度计算相对变化；松手保留可见偏移，不回弹、不继续残余转向。指针在区域外释放、取消捕获或窗口失焦时结束拖动。
- 暂停停止自动前进和天空、薄雾的时间推进；仍允许明确的鼠标拖动观察。继续从原位置接续，按钮文案与真实状态一致。
- 「走入山野」淡出介绍并平滑加速；「回到首页」或 Esc 恢复介绍，路线保持连续。当前进入/退出操作会恢复自动漫游。退出时恢复适当焦点。
- 手机触摸保持页面滚动；当前不提供手指拖拽转向。新增触摸操作时须同时解决滚动冲突与明确的进入/退出方式。
- 场景未就绪或不可用时显示同场景静态图，并隐藏不可用的漫游按钮。来源入口进入可阅读的 UTF-8 HTML 页面，保留署名与返回入口。
- 首屏 HTML 自带山景预览，外部图片未加载时仍有景物。静态图解码后渐显；三维首帧完成交接后才提供漫游控制并启动相机，清晰度增强不突然替换画面。
- 同一标签页刷新可用成对保存的截图与相机状态接续，包括暂停、观察角度和进入山野状态。当前记录保留 15 分钟，匹配屏幕比例与桌面/手机模式；存储失败或记录不适用时正常开场。新访问和站内返回不使用上次截图。

### 在野电台

- 默认不自动播放，刷新后也需点击播放。记住频道、曲目与音量；不要把记忆偏好等同于播放授权。新访客默认「旅行与自由」，首曲为《没有时刻表》。
- 展开、收起、打开曲库、关闭曲库不改变播放状态。Esc 在频道选择中先返回歌单，再关闭电台；外部点击可收起面板。电台操作不退出正在进行的山野漫游；电台是非模态浮层，页面其余区域仍可操作。
- 站内切页保留同一个音频实例、当前进度和播放意图；初始化防重复，避免叠音或新增事件监听器重复响应。
- 底部「曲库」展开当前歌单，歌单标题旁的「换频道」进入频道选择；「返回歌单」或选中频道回到曲目列表。两个视图共用一块区域，频道选择不另行增加面板高度；频道和歌曲仅当前视图可操作。曲库完全收起后再次打开从歌单开始。
- 播放列表只显示当前频道。暂停时切换频道保持暂停；前台播放中切换先淡出 `160ms`，新曲播放后淡入 `480ms`。点击当前频道不重置曲目或进度，快速切换以最后一次选择为准。
- 后台播放与自动续播不依赖动画帧。页面隐藏时立即完成尚未结束的切歌与音量过渡，维持用户音量和静音选择；返回时按音频实际时间更新进度，不因可见性变化恢复用户已暂停的音乐。
- 选曲与上/下一首开始所选曲目，曲目结束后在当前频道循环。封面、标题、进度、按钮文案和选中项同步更新。唱片中心、面板、歌单和系统媒体信息共享曲目封面；缺图或加载失败使用公共默认封面。
- 收起时唱片为 `50px` 深绿圆底（`#1f3028`）与 `36px` 圆形封面，不叠加唱片纹路或封面描边；保留播放时缓慢旋转。
- 音频仅在播放或主动调整进度时加载。失败时提供中文说明和重试/换歌路径，保留可操作入口。
- 频道、曲目与封面从 [`src/data/radio.ts`](../src/data/radio.ts) 和 `public/music/<id>/` 维护；版本与曲库清单见 [README](../README.md#在野电台)。AI 音乐保留「AI 生成」标注，公开资源只放播放所需文件。

## 响应式、可访问性与生命周期

### 窄屏与浮层

主布局断点为 `1100px`、`760px`；电台在 `600px` 以下调整浮层尺寸和安全区，极窄屏 `360px` 以下隐藏山形标志、缩小首页标题。订阅表单在 `640px` 以下堆叠。沿用组件各自的实际断点，不要求所有组件同时改列。

五项主导航在 ≤600px 时置于品牌下方，保留全部文字入口与每项至少 `44 × 44px` 的触摸区域。对应首页漫游按钮顶部为 `132px`，首屏最小高度 `620px`；高度 ≤680px 的手机收紧文案间距、最小高度回到 `560px`，让底部探索仍可见。新增导航后需同时核对首页、内页、锚点及吸顶页头，避免标题或定位内容被遮住。

随笔用行间距与细线区分短篇，不为每则内容添加独立入场动画。足迹地图不持续运动；选中通过实心圆点和地名下划线提示，颜色与圆点变化约 `250–350ms`。地图选择展开对应记录，必要时滚动至可见位置并将焦点移到该记录；键盘可原位开合，减少动态效果时直接完成。空状态沿用纸色与细线，线稿保持静止；≤600px 且高度 ≤680px 时隐藏装饰线稿、收紧间距，保留说明与跳转入口。内容维护方式见 [README](../README.md#随笔与足迹)。

随笔可有短标题（桌面 `26px`、手机 `23px`），图片与图注跟随正文；有明确前后关系的两张图片可以并排，手机顺序堆叠。原图和 AI 生成图片分别标注。日期可按记录本身的精度展示月份范围，仍按年份倒序阅读。照片图注使用 `11px / 1.8` 无衬线字体，拍摄日期放在画面描述旁，不另写未经核实的旅行叙述。

桌面保留多列层次，手机按阅读顺序堆叠；手机漫游按钮移至页头下方，避开底部电台与向下入口。电台边缘当前为桌面 `24px`、手机 `12px`，结合 `env(safe-area-inset-*)`；面板受视口宽高约束，长内容在内部滚动，面板标题与收起按钮保持可见。高度 ≤680px 时缩减封面至 `64px`、适度收紧操作间距。新增固定入口需检查与这些区域的碰撞。

曲库内容区当前最大高 `228px`，包含 `44px` 标题行；高度不足时按播放控制下方的实际剩余空间收紧，歌曲和频道各自在内部滚动。视口高度 ≤520px 时，封面缩至 `56px`、播放按钮缩至 `48px`，同时收紧间距。浏览频道时保持播放器主体位置不变；切换歌曲导致标题自然换行时，面板平滑调整高度。极短视口允许整个面板滚动，保证所有控制仍可到达。

目前页头、阅读进度、电台和跳到正文入口的 `z-index` 分别为 `20 / 25 / 40 / 100`。新浮层按实际遮挡需求决定层级，检查背景是否仍可点击和聚焦。

链接使用链接语义，动作使用按钮；保持可见键盘焦点、纯图标名称、目录当前项及状态播报。主要操作沿用现有接近 `44px` 的可点击区域；紧凑控件同时检查触摸间隔。来源、订阅和错误说明使用正常页面与中文文案，不向访客展示调试信息。新增输入框应有标签，长内容不得造成页面横向溢出。

### 性能与导航

- Three.js 场景只在需要的首页动态加载。减少动态效果、节省流量或 WebGL 不可用时保留静态首页；不要把重型场景依赖带到普通内容页的首次加载中。
- 当前桌面/手机地形网格分段为 `768 / 384`；桌面实际绘图尺寸的长边低于 `1024px` 时也使用 `384` 分段。像素比上限为 `1.65 / 1.35`；手机约 `30 FPS` 并省略体积雾后处理，检测到性能不足时只降低像素比，不提高已有的低密度设置。这些是实现参数，不是对所有设备的性能保证。
- 离开首屏或隐藏标签页停止场景渲染，切换页面释放观察器、事件、动画、纹理和 WebGL 资源。未完成的加载也应能取消，返回首页只创建一个场景。
- 全站电台通过 `transition:persist` 保留；普通页面脚本在 `astro:before-swap` 清理，并按页面幂等初始化。文字入场从 CSS 首次绘制开始，完成后不因脚本或偏好变化重复。新增脚本先判断自身是跨页持久功能还是页面局部功能，再选择生命周期。
- 高程解码、网格、法线计算和纹理解码在 Worker 中执行，通过可转移缓冲区交给渲染器；大纹理按条带分批上传，每批之间让出主线程，全部上传后才加入画面。首帧着色器预编译与上传安排在文字入场后。离页中断尚未完成的计算与加载。
- 场景静态图与三维开场构图保持一致；调整相机开场时同步更新桌面、手机首帧。局部高清资源失败时仍能展示完整底图，核心资源失败时回退静态图。
- 使用本地压缩图片、字体和音频；署名与许可随可公开资源保留。正文、导航和返回入口不能依赖 WebGL 正常运行。

## 新功能的实现路径

1. **选择相邻模式。** 文章条目复用 `ArticleCard`；作品条目复用 `ProjectCard`；说明/工具页以 `BaseLayout`、`.section`、`.container` 和 `.page-heading` 开始；只有需要新交互语义时再增加组件。
2. **分配样式位置。** [`global.css`](../src/styles/global.css) 保存基础变量、内容排版与基础响应式；[`experience.css`](../src/styles/experience.css) 在其后加载，保存当前视觉与交互增强；组件局部样式处理自身特例。修改前查看最终生效规则，避免只改前层后又被覆盖。新增组件使用有归属的类名和局部选择器。
3. **沿用动效职责。** 文字入场由 CSS 执行，[`motion.ts`](../src/scripts/motion.ts) 记录完成状态并负责作品详情和阅读反馈；[`radio.ts`](../src/scripts/radio.ts) 负责电台状态和过渡；[`landscape.ts`](../src/scripts/landscape.ts) 加载场景，[场景实现](../src/lib/landscape.ts) 与 [薄雾实现](../src/lib/landscape-atmosphere.ts) 管理渲染。不要为同一元素叠加互相竞争的 CSS 和脚本动画。
4. **完整定义状态。** 按功能需要覆盖默认、悬停、键盘焦点、按下、展开/选中、加载/失败，以及手机和减少动态效果状态。状态文案说明动作或下一步，例如「重试播放」「复制订阅地址」。
5. **按影响范围验收。** 使用下表选择检查。有意改变共用原则或参数后同步更新本规范；截图也应反映已确认的新设计。

## 交付验收

自动化用例与运行方式见 [测试说明](testing.md)。按下表选择受影响的测试，并补充实际页面检查。

| 改动范围 | 必须核对的结果 |
| --- | --- |
| 仅文档 | 色值、尺寸、行为与代码一致；文件和截图链接可用；未把未实现的能力写成现状。 |
| 文字、图片、内容数据 | 长标题、中文字体、换行和图片比例正常；署名与必要来源仍可找到；按实际内容检查关联页面。 |
| 公共样式、字体或布局 | 首页、文章列表、作品页、文章详情和一个说明页保持一致；在 `1440px`、`768px`、`390px`、`320px` 检查层级、留白、溢出与覆盖。改变断点时补查断点两侧。 |
| 展开组件或浮层 | 连续快速切换、动画中反向、尺寸变化和短屏（如 `320 × 568`）后正确收敛；没有空壳、裁切或焦点丢失；键盘和减少动态效果可用。 |
| 电台或客户端导航 | 播放与选曲、歌单、音量/进度、收起、切页、返回、失败重试均符合约定；页面跳转不叠音、不重置音频。 |
| 山野或输入控制 | 暂停/继续、进入/退出、悬停不转向、拖拽转向、松手保持、区域外释放和失焦正常；导航/按钮不误触拖拽。修改路线时检查完整环线、接点连续、地面穿透与边界。 |
| 场景加载或性能 | 普通桌面、手机、减少动态效果、核心资源失败和 WebGL 丢失下都有正确结果；切页和隐藏页面停止无用渲染，返回后没有重复实例。 |
| 应用代码或依赖 | `npm run check`、`npm run build`、差异检查通过；在实际页面完成受影响交互的验证，不能仅凭编译成功判断视觉正确。 |

视觉验收比较构图、字体、色系、留白和组件层级。拍摄前等待字体及入场动画完成，山景暂停后对照；不将动态景物位置或字体抗锯齿差异当作必然退步。动效另行检查中间帧与连续操作，静态截图不能证明它流畅。纯文档修改不要求重跑整站功能测试。
